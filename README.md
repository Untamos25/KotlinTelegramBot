# Telegram-бот для изучения английских слов / English word learning Telegram bot

### 1. Описание

Этот проект представляет собой Telegram-бота, разработанного для помощи в изучении иностранных слов. Бот использует методику интервальных повторений: он предлагает пользователю слова для перевода до тех пор, пока они не будут выучены (по умолчанию, после 3 правильных ответов).

**Основные возможности:**

*   **Интерактивное обучение:** Вопросы с вариантами ответов в виде кнопок.
*   **Отслеживание прогресса:** Бот подсчитывает статистику выученных слов и показывает ваш прогресс в процентах.
*   **Персонализация:** Для каждого пользователя создается свой словарь и отслеживается индивидуальный прогресс.
*   **Сброс прогресса:** Возможность начать обучение с нуля.

### 2. Запуск и использование

Бот размещен на сервере и готов к использованию.

1.  Найдите бота в Telegram по имени пользователя: [@EnglishWordsTGBot](https://t.me/EnglishWordsTGBot)

### 1. Description

This project is a Telegram bot designed to help users learn english words. The bot uses a spaced repetition system: it presents words for translation until they are considered learned (by default, after 3 correct answers).

**Key features:**

*   **Interactive learning:** Questions with multiple-choice answers presented as buttons.
*   **Progress tracking:** The bot calculates statistics on learned words and shows your progress as a percentage.
*   **Personalization:** A separate dictionary and progress are maintained for each user.
*   **Progress reset:** You can reset your progress and start over at any time.

### 2. Launch and usage

The bot is already hosted and ready to use.

1.  Find the bot in Telegram by its username: [@EnglishWordsTGBot](https://t.me/EnglishWordsTGBot)
2.  Send the `/start` command.
3.  Use the menu buttons to navigate.

### 3. Technologies

*   **Kotlin:** The primary programming language.
*   **Telegram Bots API:** For interacting with the Telegram platform.
*   **Kotlinx.Serialization:** For parsing JSON responses from the Telegram API.
*   **Java HttpClient:** For making HTTP requests to the API.
*   **File I/O:** For storing dictionaries and user progress.
